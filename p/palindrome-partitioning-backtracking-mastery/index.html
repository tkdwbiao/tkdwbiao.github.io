回溯算法：分割回文串——如何在字符串上‘动手术’？

2026-04-01 15:52
阅读时长: 3 分钟

在 [LeetCode 131. 分割回文串] 中，我们要把一个字符串切割成若干段，使每一段都是回文。这要求我们不仅要掌握回溯的搜索逻辑，还要具备对“合法性”的即时判断能力。

一、 核心思想：切割问题的本质

阿彪认为，切割问题本质上是关于 “间隙”的选与不选 。

1. 物理模型：间隙决策

假设字符串是 aaab：

  • 在第一个 a 后面有一个间隙。
  • 选（切下去）：第一段定格为 "a"，剩下的 "aab" 继续递归。
  • 不选（不切）：第一个 a 暂时不独立，和后面连起来变成 "aa"，再看下一个间隙。

2. 决策树逻辑

  • 每一个节点：代表当前还没切完的剩余字符串。
  • 每一条分支：代表你尝试“落刀”的位置。
  • 合法性要求：只有当你切下的这一段是回文时，这一刀才算成功，才能继续往下切。

二、 基础阶段：直觉驱动的 DFS 过程流

1. 过程 (Process)

我们以 s = "aaab" 为例，还原计算机执行 DFS 时的“心跳顺序”：

  1. a (0:1) ✅ $\to$ a (1:2) ✅ $\to$ a (2:3) ✅ $\to$ b (3:4) ✅ $\to$ 【结果：a,a,a,b】
  2. 回溯，尝试 ab (2:4) ❌（不选 2:3 的切点，尝试 2:4）
  3. 回溯，尝试 aa (1:3) ✅ $\to$ b (3:4) ✅ $\to$ 【结果：a,aa,b】
  4. 回溯，尝试 aab (1:4) ❌
  5. 回溯，尝试 aa (0:2) ✅ $\to$ a (2:3) ✅ $\to$ b (3:4) ✅ $\to$ 【结果：aa,a,b】
  6. 回溯，尝试 aaa (0:3) ✅ $\to$ b (3:4) ✅ $\to$ 【结果：aaa,b】

阿彪总结：这一串看似乱序的路径，其实是算法在决策树上留下的真实脚印。

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        res = []
        path = []

        def is_palindrome(word):
            return word == word[::-1]

        def backtrack(start_index):
            if start_index >= len(s):
                res.append(path[:])
                return

            for i in range(start_index, len(s)):
                sub = s[start_index : i + 1]
                # “选”这个切点的前提是：当前子串必须是回文
                if is_palindrome(sub):
                    path.append(sub)
                    backtrack(i + 1) # 递归
                    path.pop() # 回溯：撤销选择，去试下一个更长的子串

        backtrack(0)
        return res

三、 优化阶段：预处理回文状态

1. 思想 (Idea)

在基础版中，如果字符串里有大量重复字符（如 “aaaaa”），我们会重复检查同一个子串是否为回文。 阿彪进阶方案：利用 动态规划 (DP) 提前算出一张“回文地图”。

2. 过程 (Process)

  1. 创建二维数组 is_pal[i][j]。
  2. 状态转移：is_pal[i][j] = (s[i] == s[j]) and is_pal[i+1][j-1]。
  3. 填表顺序：由于依赖左下角，必须从下往上填。

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        res = []
        path = []
        
        # 1. DP 预处理：O(N^2) 时间复杂度
        is_pal = [[True] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            for j in range(i + 1, n):
                is_pal[i][j] = (s[i] == s[j]) and is_pal[i + 1][j - 1]

        def backtrack(start):
            if start == n:
                res.append(path[:])
                return

            for i in range(start, n):
                # 2. O(1) 查表判断，极致提速
                if is_pal[start][i]:
                    path.append(s[start : i + 1])
                    backtrack(i + 1)
                    path.pop()

        backtrack(0)
        return res

四 : 阿彪的深度总结 [抱拳]

1. “选与不选”的艺术

切割问题是在每一个可能的切点做决策。选了，就是一段独立子串；不选，就合入更大的子串。这种决策构成了回溯的深度和广度。

2. 性能与逻辑的权衡

维度基础版优化版
回文检查$O(N)$ (重复翻转)$O(1)$ (一次预处理)
空间复杂度$O(N)$ (递归栈)$O(N^2)$ (存储 DP 表)
适用场景字符串较短字符串较长且重复多
