二叉树重构：从前序与中序‘拼’出一棵树的进阶之路

2026-03-30 15:00
阅读时长: 3 分钟

LeetCode 105 要求我们根据前序遍历和中序遍历的结果，还原出原始的二叉树。这不仅是一道算法题，更像是一场逻辑严密的拼图游戏。

1. 核心思想：两把尺子的联动

重构的关键在于利用两种遍历的不同特性：

  1. 前序遍历 (Preorder)：[ 根节点 | 左子树所有节点 | 右子树所有节点 ]
    • 作用：它是“指挥官”，第一个元素永远是当前的根节点。
  2. 中序遍历 (Inorder)：[ 左子树所有节点 | 根节点 | 右子树所有节点 ]
    • 作用：它是“定位仪”，一旦确定了根节点，左边就是左子树的地盘，右边就是右子树的地盘。

2. 基础版：直觉驱动的切片法

这个版本最符合人类的大脑直觉：找到根，切开数组，扔给递归。

🚀 实现逻辑：

  1. 取出 preorder[0] 作为根节点。
  2. 在 inorder 中找到这个根的索引 mid。
  3. 切分：
    • inorder 被切成 [:mid] 和 [mid+1:]。
    • preorder 相应地切出左子树和右子树的长度。

class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        # 基准情况：数组空了，说明没节点了
        if not preorder or not inorder:
            return None
        
        # 1. 前序遍历的第一个就是根
        root_val = preorder[0]
        root = TreeNode(root_val)
        
        # 2. 找到根在中序遍历中的位置
        mid = inorder.index(root_val)
        
        # 3. 递归构建（利用 Python 切片）
        # 左子树：前序跳过根，取 mid 个；中序取 mid 之前
        root.left = self.buildTree(preorder[1:mid+1], inorder[:mid])
        # 右子树：前序取 mid+1 之后；中序取 mid 之后
        root.right = self.buildTree(preorder[mid+1:], inorder[mid+1:])
        
        return root
  • 缺点：.index() 是 $O(N)$ 的，切片 [:] 会产生数组副本（空间 $O(N)$），总复杂度退化为 $O(N^2)$。

3. 进阶版：极致性能的指针法（$O(N)$）

为了达到大厂面试的性能要求，我们需要进行两项“手术”：

  1. 哈希表加速：预处理 inorder，让查找根位置变成 $O(1)$。
  2. 下标传递：不再切分数组，只传递左右边界的索引。

🚀 优化点拆解：

  • index_map：一次性记录所有数值在中序数组里的位置。
  • left_size：通过中序位置算出左子树到底有多少人，这是连接两把尺子的唯一纽带。

class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        # 1. 预处理：哈希表记录中序下标，空间换时间
        index_map = {val: i for i, val in enumerate(inorder)}
        
        def myBuildTree(pre_l, pre_r, in_l, in_r):
            # 边界：范围无效则返回
            if pre_l > pre_r:
                return None
            
            # 2. 确定根节点（前序左边界）
            root_val = preorder[pre_l]
            root = TreeNode(root_val)
            
            # 3. O(1) 定位中序位置
            in_root_idx = index_map[root_val]
            
            # 4. 计算左子树规模（纽带）
            left_size = in_root_idx - in_l
            
            # 5. 递归划分边界
            # 左子树：前序 [pre_l+1, pre_l+left_size], 中序 [in_l, in_root_idx-1]
            root.left = myBuildTree(pre_l + 1, pre_l + left_size, in_l, in_root_idx - 1)
            # 右子树：前序 [pre_l+left_size+1, pre_r], 中序 [in_root_idx+1, in_r]
            root.right = myBuildTree(pre_l + left_size + 1, pre_r, in_root_idx + 1, in_r)
            
            return root

        n = len(preorder)
        return myBuildTree(0, n - 1, 0, n - 1)

4. 阿彪的横向对比与总结 [抱拳]

特性基础版（切片）进阶版（下标+哈希）
时间复杂度$O(N^2)$$O(N)$
空间复杂度$O(N^2)$ (频繁复制)$O(N)$ (仅哈希表)
代码可读性极佳，一眼懂稍复杂，需细心
面试评价逻辑通顺，但功底待加强专业、严谨、大厂范儿

💡 阿彪的避坑口诀：

  • 切片左闭右开：preorder[1 : mid+1] 包含 1，不包含 mid+1。
  • Left_Size 是灵魂：它是前序数组中左子树的“点名长度”。
  • Map 必须外提：哈希表只能建一次，不能放进递归里。
