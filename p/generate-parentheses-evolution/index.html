回溯算法进阶：括号生成的三重境界——从‘填空’到‘布局’

2026-04-01 14:40
阅读时长: 3 分钟

LeetCode 22. 括号生成 要求我们生成所有有效的括号组合。这道题是练习回溯算法（Backtracking）及其“剪枝”技巧的绝佳素材。今天阿彪带大家从三种视角拆解这道题。

境界一：初出茅庐——成员变量手动回溯

这是阿彪最初的思路。我们使用 self 记录左括号和右括号的使用数量。

💡 核心思想：

维护两个全局计数器。在递归“进门”时增加计数，在递归“出门”时手动减少计数。

class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        self.left = 0
        self.right = 0
        res = []
        path = []
        
        def backtrack():
            # 1. 终止条件：总长度达到 2n
            if len(path) == 2 * n:
                res.append("".join(path))
                return

            # 2. 决策：选左括号
            if self.left < n:
                self.left += 1
                path.append("(")
                backtrack()
                # 【关键】手动还原状态：撤销选择
                path.pop()
                self.left -= 1
            
            # 3. 决策：选右括号（只有右括号比左括号少时才有效）
            if self.right < self.left:
                self.right += 1
                path.append(")")
                backtrack()
                # 【关键】手动还原状态
                path.pop()
                self.right -= 1
                
        backtrack()
        return res

阿彪反思： 由于 self.left 是全局共享的，修改后必须手动 self.left -= 1。这种写法虽然稍显繁琐，但最能体现回溯“清理现场”的本质。

境界二：登堂入室——函数参数自动回溯

通过将计数器作为函数参数传递，我们可以利用函数调用栈的特性，让状态自动复原。

💡 核心思想：

参数传递就像给下一层发了一份“复印件”。下层怎么改，都不影响我这一层的原始数据。

class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        res = []
        path = []

        def backtrack(left, right):
            if len(path) == 2 * n:
                res.append("".join(path))
                return

            # 只要左括号有剩余就加
            if left < n:
                path.append("(")
                # 传入 left + 1，本层的 left 值不变，无需手动回减
                backtrack(left + 1, right)
                path.pop() 

            # 只要右括号少于左括号就加
            if right < left:
                path.append(")")
                backtrack(left, right + 1)
                path.pop() 

        backtrack(0, 0)
        return res

阿彪反思： 这种写法是面试中的黄金准则。代码简洁、逻辑纯粹，利用栈帧自动管理数值变量的回溯，仅需手动处理列表（path）的 pop。

境界三：炉火纯青——灵神的坐标布局法

这是来自 灵茶山艾府 的进阶思路。它不再一格一格填符号，而是通过“安插左括号位置”来带动全局。

💡 核心思想：

既然总共有 $2n$ 个位置，如果我们定下了 $n$ 个左括号的坐次，剩下的坑位必然全是右括号。

  • 动作合并：每一步考虑“填入若干个右括号 + 1 个左括号”。

class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        ans = []
        path = [] # 这里记录的是左括号的【下标】

        # i: 当前扫描到的总位置, balance: 剩余可抵消的左括号数
        def dfs(i, balance):
            if len(path) == n:
                # 布局完成：根据下标生成最终字符串
                s = [')'] * (n * 2)
                for j in path: s[j] = '('
                ans.append("".join(s))
                return

            # 枚举这一波要填入几个右括号 (0 到 balance 个)
            for right in range(balance + 1):
                # 填入 right 个右括号后，必须紧跟一个左括号，记录其位置
                path.append(i + right)
                # 推进：位置移动 right+1 位，余额更新为 balance - right + 1
                dfs(i + right + 1, balance - right + 1)
                path.pop() # 恢复现场

        dfs(0, 0)
        return ans

阿彪反思： 这个解法将递归深度从 $2n$ 压缩到了 $n$。它通过 range(balance + 1) 在循环层面就锁死了“右括号不能超过左括号”的规则，是一种极其优雅的“降维打击”。
