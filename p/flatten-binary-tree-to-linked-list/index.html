二叉树‘拉直’术：从先序遍历到原地修改的进化

2026-03-28 23:20
阅读时长: 2 分钟

LeetCode 114. 二叉树展开为链表 要求我们将树展开成一个只有右孩子的“链表”，且顺序符合先序遍历。

阿彪通过这道题，带大家看透从“空间换时间”到“原地修改”的逻辑跨越。

1. 阿彪的稳健方案：分步重组

最稳的方法是：先把顺序定下来，再把线接上去。

逻辑：

  1. 先序遍历：通过递归，将所有节点按顺序存入列表 preorderList。
  2. 指针重连：
    • 令 pre.left = None。
    • 令 pre.right = cur。

class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        """
        Do not return anything, modify root in-place instead.
        """
        preorderList = list()
        def preorderTraversal(root):
            if root:
                preorderList.append(root)
                preorderTraversal(root.left)
                preorderTraversal(root.right)
        preorderTraversal(root)
        size = len(preorderList)
        for i in range(1, size):
            pre,cur = preorderList[i-1],preorderList[i]
            pre.left = None
            pre.right = cur
  • 复杂度：时间 $O(N)$，空间 $O(N)$。

2. 进阶挑战：原地修改 ($O(1)$ 空间)

面试官往往会问：“如果不给用数组，你能直接在树上动手术吗？”

核心黑科技：寻找“接班人”

先序遍历的顺序是：根 -> 左子树 -> 右子树。 这意味着，右子树 必须接在 左子树最后访问的那个节点 后面。

手术步骤：

  1. 只要当前节点有左子树。
  2. 找到左子树里“最右”的那个节点（它是左子树先序遍历的终点）。
  3. 把当前的右子树整个“嫁接”到那个最右节点的右边。
  4. 把左子树整体搬到右边，左边切断。

“这就像是在拆迁，把右边的楼搬到左边楼的最顶层，然后再把左边的楼整体挪到右边。”

class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        curr = root
        while curr:
            if curr.left:
                # 1. 找左子树的最右节点（前驱节点）
                predecessor = curr.left
                while predecessor.right:
                    predecessor = predecessor.right
                
                # 2. 把原来的右子树接到前驱节点的右边
                predecessor.right = curr.right
                
                # 3. 把左子树换到右边，左边清空
                curr.right = curr.left
                curr.left = None
            
            # 4. 继续下一个节点
            curr = curr.right

3. 阿彪的面试避坑指南 [抱拳]

  1. 题目要求：展开后的链表依然使用 TreeNode，而不是 ListNode。
  2. 左孩子必须置空：面试中很多人忘了 pre.left = None，导致树结构混乱。
  3. 原地修改的优势：进阶算法不涉及递归（迭代实现），完全省去了系统栈空间和数组空间，是真正的 $O(1)$。
