全排列的两重境界：回溯法的‘后悔药’与插空法的‘步步为营’

2026-03-31 20:10
阅读时长: 3 分钟

全排列（LeetCode 46）是每一位算法学习者的必修课。这道题最精彩的地方在于，它既可以用 回溯（Backtracking） 这种“递归试错”的思维解决，也可以用类似 动态规划（DP） 的“插空递增”逻辑搞定。

一、 境界一：回溯法（迷宫试错）

1. 核心思想：进门拿走，出门还回来

回溯法的本质是 深度优先遍历（DFS） 一棵决策树。

  • 做选择：你走进一间屋子，拿走一个数字，并打上“已使用”的标签。
  • 去深处：带着剩下的数字继续进下一间屋子。
  • 撤销选择：当你从屋子出来时，必须把数字放回原处，并撕掉标签。

“回溯的灵魂就是‘撤销’，它给了算法吃‘后悔药’的机会。”

class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        res = []    # 结果集
        path = []   # 路径记录
        used = [False] * len(nums) # 状态标记

        def backtrack():
            # 1. 终止条件：路走到底了
            if len(path) == len(nums):
                res.append(path[:]) # 必须存副本
                return

            # 2. 尝试每一种可能
            for i in range(len(nums)):
                if used[i]: continue # 拿过的不能再拿
                
                # 做选择
                used[i] = True
                path.append(nums[i])
                
                # 递归进入下一层
                backtrack()
                
                # 撤销选择（回溯的关键！）
                path.pop()
                used[i] = False

        backtrack()
        return res

二、 境界二：插空法（增量构建）

1. 核心思想：新来的插哪儿？

这是一种迭代的思维（也是一种 DP 思想）。假设我们已经知道了 $n-1$ 个数字的所有全排列，那么对于第 $n$ 个数字，我们只需要把它插入到之前每个排列的每一个缝隙里。

2. 举例：[1, 2, 3]

  1. 初始：[[]]
  2. 处理 1：插在 [] 唯一的缝隙 $\rightarrow$ [[1]]
  3. 处理 2：插在 [1] 的缝隙（左、右） $\rightarrow$ [[2,1], [1,2]]
  4. 处理 3：
    • 拿 [2,1]，插在 3 个缝隙 $\rightarrow$ [3,2,1], [2,3,1], [2,1,3]
    • 拿 [1,2]，插在 3 个缝隙 $\rightarrow$ [3,1,2], [1,3,2], [1,2,3]

class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        dp = [[]] # 基础状态：空的一种排列
        
        for num in nums:
            new_dp = []
            # 拿出上一轮算好的所有排列
            for curr_perm in dp:
                # 在当前排列的所有缝隙中插入新数字
                # 长度为 L 的排列有 L+1 个缝隙
                for i in range(len(curr_perm) + 1):
                    # 组合成新排列
                    new_dp.append(curr_perm[:i] + [num] + curr_perm[i:])
            dp = new_dp
            
        return dp

三、 阿彪的深度复盘与对比 [抱拳]

1. 复杂度分析

  • 时间复杂度：两者均为 $O(n \cdot n!)$。全排列共有 $n!$ 种，每种处理需要 $O(n)$。
  • 空间复杂度：
    • 回溯法：$O(n)$。递归栈深度和状态数组。
    • 插空法：$O(n \cdot n!)$。需要存储每一层产生的所有中间排列。

2. 面试怎么选？

  • 回溯法：是工业级标准答案。它能处理更复杂的约束（比如去重、剪枝），且空间利用率更高。
  • 插空法：展示了你多维的思维。如果你对递归深度有顾虑，或者想展示对排列组合数学本质的理解，这是一个非常惊艳的视角。

3. 阿彪的细节警示

  • 回溯必传副本：res.append(path[:])。在 Python 中不加 [:] 存的是引用，最后 res 里的列表都会随着回溯变成空的。
  • 状态重置：回溯中 used[i] = False 和 path.pop() 必须是成对出现的“镜像动作”。
