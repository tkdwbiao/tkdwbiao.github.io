数组轮转的三重境界：从空间换时间到 O(1) 乾坤大挪移

2026-03-30 14:00
阅读时长: 3 分钟

LeetCode 189. 轮转数组 要求我们将数组向右轮转 $k$ 个位置。这道题最迷人的地方在于：如何在 $O(n)$ 时间 和 $O(1)$ 空间 的严苛约束下，优雅地完成位移？

今天阿彪带大家拆解三种境界的解法。

0. 准备工作：取余的艺术

无论用哪种方法，第一步必须是 k %= n。 理由：如果数组长度为 5，轮转 6 次和轮转 1 次的效果是一样的。不做取余，遇到 $k$ 极大的测试用例会产生大量无效计算。

1. 第一重境界：空间换时间（辅助数组）

这是最符合直觉的“搬家”法。

💡 核心思想

建立一个同样大小的新数组，根据公式 (当前下标 + k) % n 直接计算出每个元素的新位置，直接填进去。

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        # 1. 开辟新空间
        new_nums = [0] * n
        for i in range(n):
            # 2. 计算新位置并存放
            new_nums[(i + k) % n] = nums[i]
        # 3. 拷贝回原数组
        nums[:] = new_nums
  • 优点：逻辑极其简单，不容易出 Bug。
  • 缺点：空间复杂度 $O(n)$，在内存受限的情况下不是最优选。

2. 第二重境界：三步翻转法（阿彪推荐 🌟）

这是面试官最想看到的解法，利用了对称性的美学。

💡 核心思想

通过三次镜像翻转，巧妙地改变元素的前后顺序：

  1. 全员反转：把末尾的 $k$ 个元素“拽”到前面，但顺序是反的。
  2. 翻转前 $k$ 个：修正前段顺序。
  3. 翻转后 $n-k$ 个：修正后段顺序。

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        
        def reverse(l, r):
            while l < r:
                nums[l], nums[r] = nums[r], nums[l]
                l, r = l + 1, r - 1
        
        reverse(0, n - 1) # 全局翻转
        reverse(0, k - 1) # 翻转前 k 个
        reverse(k, n - 1) # 翻转剩下的
  • 复杂度：时间 $O(n)$，空间 $O(1)$。
  • 阿彪点评：代码极其优雅，是处理“局部整体位移”的万能模版。

3. 第三重境界：环状替换（数学硬核版）

如果你想向面试官展示深厚的数学功底，请祭出这一招。

💡 核心思想：接力赛

  1. 从 nums[0] 开始，把它直接送到目的地 (0+k)%n。
  2. 拿着被挤出来的那个人，继续送往下一个目的地。
  3. 关键挑战：如果 $n$ 和 $k$ 有公约数，你会陷入小循环（如 $n=6, k=2$，只会换 0-2-4 位置）。
  4. 对策：使用一个 count 变量记录移动次数。如果回到了起点但还没换完 $n$ 个，则起点 $+1$ 开启新的一轮接力。

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        count = start = 0
        while count < n:
            curr = start
            prev_val = nums[start]
            while True:
                next_idx = (curr + k) % n
                # 交换手里拿的数和目的地的数
                nums[next_idx], prev_val = prev_val, nums[next_idx]
                curr = next_idx
                count += 1
                # 如果回到起点，说明这一轮小接力结束了
                if start == curr: break
            start += 1
  • 复杂度：时间 $O(n)$，空间 $O(1)$。
  • 阿彪点评：这是真正的“原地挪动”，每个元素只被移动一次，效率极高。

阿彪的避坑复盘 [抱拳]

  1. Python 赋值陷阱：在修改原数组时，必须写 nums[:] = ... 而不是 nums = ...。后者只是改变了变量的指向，并没有修改传入的原始对象。
  2. 理解 $O(1)$：环状替换和三步翻转都只用了常数个变量，这在处理百万级数据时能省下巨大的内存。
