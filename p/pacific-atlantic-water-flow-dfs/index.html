逆向思维的艺术：深度拆解『水流问题』的 DFS 补完计划

2026-04-03 14:36
阅读时长: 3 分钟

在网格搜索问题中，有些题目正着做是 $O((N \times M)^2)$，倒着做却是 $O(N \times M)$。今天阿彪带大家通过 103. 高山流水，领略逆向 DFS 的魅力。

一、 核心思想：以终为始

题目要求：寻找既能流向“边界A”又能流向“边界B”的所有点。

  • 直觉（正向）：对每一个点都跑一遍搜索，看能不能流到边缘。
    • 瓶颈：重复计算太多，时间复杂度爆炸。
  • 阿彪的逆向思维： 想象大海的水往陆地上倒灌。如果水能从边缘“逆流”爬到一个点，说明这个点未来就能“顺流”下海。
    • 规则改变：原本是“高往低流”，逆向搜索变成“只要邻居不低于我，我就能爬过去”。

二、 解题方法：双路染色法

  1. 建立两张地图：first_visited 和 second_visited。
  2. 边缘灌水：
    • 从左、上边界开始 DFS，标记所有能到达的陆地。
    • 从右、下边界开始 DFS，标记所有能到达的陆地。
  3. 寻找交集：同时在两张地图上都被标记为 True 的点，就是我们要找的英雄。

三、 举例说明：2x2 矩阵

1
2

[1, 2]
[4, 3]
  • 第一组（左、上）灌水：
    • 从 (0,0) 开始，1 可以爬到 2 和 4。
    • first_visited 全为 True。
  • 第二组（右、下）灌水：
    • 从 (1,1) 开始，3 可以爬到 4（3->4），但爬不到 2（3->2 也可以，假设高度允许）。
    • 如果最终 (1,0) 也就是高度 4 的点两边都通，它就是答案。

import sys
# 增加递归深度，防止大矩阵导致栈溢出
sys.setrecursionlimit(100000)

def solve():
    # # 1. 读取行数 n 和列数 m
    # try:
    #     input_data = sys.stdin.read().split()
    #     if not input_data: return
    #     n, m = int(input_data[0]), int(input_data[1])
        
    #     grid = []
    #     idx = 2
    #     for i in range(n):
    #         grid.append([int(x) for x in input_data[idx : idx + m]])
    #         idx += m
    # except: return
    
    # 1. 读 n 和 m
    line = input().split()
    if not line: return
    n, m = map(int, line)

    # 2. 读矩阵（最 Pythonic 的写法）
    grid = []
    for _ in range(n):
        grid.append(list(map(int, input().split())))

    # 2. 初始化标记矩阵
    firstvisited = [[False] * m for _ in range(n)]
    secondvisited = [[False] * m for _ in range(n)]

    def dfs(x, y, visited):
        # 进入即标记
        visited[x][y] = True
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        for dx, dy in directions:
            nx, ny = x + dx, y + dy
            # 边界检查 + 逆流检查 (邻居 >= 当前) + 未访问检查
            if 0 <= nx < n and 0 <= ny < m and not visited[nx][ny]:
                if grid[nx][ny] >= grid[x][y]:
                    dfs(nx, ny, visited)

    # 3. 四条边逆向搜索
    for i in range(n):
        dfs(i, 0, firstvisited)          # 左边
        dfs(i, m - 1, secondvisited)     # 右边

    for j in range(m):
        dfs(0, j, firstvisited)          # 上边
        dfs(n - 1, j, secondvisited)     # 下边

    # 4. 统计结果
    for i in range(n):
        for j in range(m):
            if firstvisited[i][j] and secondvisited[i][j]:
                print(f"{i} {j}")

if __name__ == "__main__":
    solve()

五 : 阿彪的深度复盘与总结 [抱拳]

1. 为什么这次代码跑通了？

  • 维度对齐：彻底分清了行（n）和列（m），不再混用。
  • 起点保护：在 dfs 入口处就标记 visited[x][y] = True，保证了边缘起点也被正确记录。
  • 逻辑闭环：判断 not visited[nx][ny] 放在了递归调用前，避免了无限死循环。

2. 时空复杂度

  • 时间复杂度：$O(N \times M)$。每个格子在两轮搜索中最多各被访问一次。
  • 空间复杂度：$O(N \times M)$。主要消耗在 visited 矩阵。
