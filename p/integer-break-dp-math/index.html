动态规划之美：深度拆解『整数拆分』的逻辑与数学奥秘

2026-03-25 13:00
阅读时长: 3 分钟

在 LeetCode 343. 整数拆分 中，题目要求将一个正整数 $n$ 拆分为至少两个正整数的和，并使这些整数的乘积最大化。

这道题是理解“子问题重叠”和“最优子结构”的绝佳案例。今天阿彪带大家从 DP 和数学两个维度彻底看透它。

1. 动态规划思路：拆还是不拆？

当我们面对一个大数字 $i$ 时，我们尝试把它拆出一个数字 $j$。剩下的部分就是 $i - j$。

此时，对于 $i - j$，我们有两种选择：

  1. 不再拆了：直接用 $j \times (i - j)$。
  2. 继续拆：既然要最大化乘积，那就用 $j \times dp[i - j]$（$dp[i - j]$ 是我们之前算出的 $i-j$ 拆分后的最大乘积）。

🚀 核心状态转移方程

$$dp[i] = \max(j \times (i - j), j \times dp[i - j])$$

其中 $j$ 的取值范围是 $[1, i/2]$。

class Solution:
    def integerBreak(self, n: int) -> int:
        # dp[i] 表示正整数 i 拆分后的最大乘积
        dp = [0] * (n + 1)
        dp[2] = 1 # 2 只能拆成 1+1，乘积为 1
        
        for i in range(3, n + 1):
            # 优化：只需遍历到 i//2，因为 j 和 i-j 是对称的
            for j in range(1, i // 2 + 1):
                # 在“直接拆成两个数”和“拆成多个数”中取最大值
                dp[i] = max(dp[i], j * (i - j), j * dp[i - j])
        
        return dp[n]

2. 深度思考：为什么需要 j * (i - j)？

阿彪在第一次做这题时也疑惑过：为什么有了 j * dp[i-j] 还要比较 j * (i-j)？

答案是： 因为 $dp[x]$ 的定义是 $x$ 至少拆分成两个数后的最大乘积。

  • 对于数字 3，$dp[3] = 1 \times 2 = 2$。
  • 如果我们算 $dp[5]$，拆出一个 2，剩下的 $i-j=3$。
  • 如果用 $j \times dp[3] = 2 \times 2 = 4$。
  • 如果用 $j \times (i - j) = 2 \times 3 = 6$。
  • 显然 $6 > 4$。也就是说，有些数字不拆比拆了乘积更大。

3. 面试加分项：数学贪心法（$O(1)$ 解法）

如果你在面试中写出了 DP 以后，面试官问：“能不能更快？”

这时候你要祭出数学规律：

  1. 尽量拆成 3：数学证明表明，将数字尽可能拆成 3，乘积最大（因为 $e \approx 2.718$，最接近它的整数是 3）。
  2. 处理余数：
    • 如果余 0：全都是 3。
    • 如果余 1：把最后一个 3 和 1 变成 $2 \times 2$（因为 $3 \times 1 < 2 \times 2$）。
    • 如果余 2：最后一个就是 2。

这种解法的时间复杂度是 $O(1)$ 或 $O(\log n)$（取决于幂运算效率）。

class Solution:
    def integerBreak(self, n: int) -> int:
        # 1. 特判小数字：因为它们拆分后的乘积比自身还小
        if n == 2: return 1
        if n == 3: return 2
        
        shang = n // 3
        yushu = n % 3
        
        # 2. 数学贪心逻辑
        if yushu == 0:
            return 3 ** shang
        elif yushu == 1:
            # 剩个 1 没用，拆一个 3 出来凑成 2*2=4
            return 3 ** (shang - 1) * 4
        else: # yushu == 2
            # 剩个 2 直接乘，不需要拆 3
            return 3 ** shang * 2

4. 复杂度分析

  • 时间复杂度：$O(n^2)$。两层嵌套循环。
  • 空间复杂度：$O(n)$。一个大小为 $n+1$ 的 DP 数组。

阿彪的技术小结 [抱拳]

  1. DP 的本质：就是把“当前的选择”和“过去的最优解”进行博弈。
  2. 初始化：$n < 2$ 没意义，$dp[2] = 1$ 是基石。
  3. 对称优化：i // 2 的小细节能让你的代码在面试官眼里显得更专业。

关于这道题的复习建议：

  1. 关于 dp[i] 的定义：一定要明确是“至少拆成两个数”。
  2. 关于 3 和 2 的选择：在 DP 过程中你会发现，从 $n=5$ 开始，$dp[n]$ 总是由 $2 \times dp[n-2]$ 或 $3 \times dp[n-3]$ 递推出来的。
  3. 对比题目：这道题和《剪绳子》是一模一样的，记住这个逻辑，可以通杀两道题。
