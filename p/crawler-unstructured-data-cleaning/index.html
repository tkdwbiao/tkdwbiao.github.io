大模型时代的数据采集工程 08：非结构化网页数据清洗

2025-12-25 10:00
阅读时长: 15 分钟

前面几篇文章里，我们已经完成了网页数据采集的基础链路：

Cookie / Session 维持状态。

XPath / CSS Selector 定位字段。
正则表达式提取局部模式。

到这里，我们已经能从页面中拿到很多字段。

但真实项目里，字段刚被提取出来时，往往并不干净。

发布时间有多种写法。
字段有时缺失，有时是“暂无”。
HTML 里有隐藏文本、脚本、样式和无关标签。
不同页面同一个字段格式不一致。

这就是数据清洗要解决的问题。

这一篇，我们专门讲：

如何把爬虫提取出来的非结构化网页数据，清洗成稳定、统一、可校验、可入库的结构化数据。

二、什么是非结构化网页数据？

非结构化数据不是完全没有结构。

它通常是：

1

人能看懂，但机器不好直接处理。

例如一段商品描述：

1

【限时优惠】Python 爬虫课程，原价 ¥399，现价 ¥199，适合有 Python 基础的同学，支持长期观看。

人可以看出：

1
2
3
4
5

原价：399
现价：199
适合人群：有 Python 基础
权益：长期观看

但机器拿到的是一整段文本。

你需要通过规则、正则、Schema、甚至 LLM，把它变成结构化字段。

网页中的非结构化数据常见来源：

  • 新闻正文。
  • 商品描述。
  • 评论内容。
  • 论坛帖子。
  • 简历信息。
  • 招聘要求。
  • 表格备注。
  • 页面 meta 描述。
  • 混合 HTML 文本。
  • script 中的状态片段。

清洗的目标不是“把文本变短”，而是让数据更可用。

import re


def normalize_space(text: str | None) -> str | None:
    if text is None:
        return None

    cleaned = re.sub(r"\s+", " ", text).strip()
    return cleaned or None

import re


def normalize_paragraphs(text: str | None) -> str | None:
    if text is None:
        return None

    lines = []
    for line in text.splitlines():
        line = re.sub(r"\s+", " ", line).strip()
        if line:
            lines.append(line)

    return "\n".join(lines) or None

字段不同，清洗策略不同：

标签去空白、去重、统一大小写
价格提取数字和单位，转数值

from bs4 import BeautifulSoup


def extract_article_content(html: str) -> str | None:
    soup = BeautifulSoup(html, "lxml")

    for tag in soup(["script", "style", "noscript"]):
        tag.decompose()

    article = soup.select_one("article") or soup.select_one(".post-content")
    if not article:
        return None

    for unwanted in article.select(".ad, .recommend, .share, .comments"):
        unwanted.decompose()

    return normalize_paragraphs(article.get_text("\n", strip=True))

def none_if_missing(text: str | None) -> str | None:

import re
from datetime import datetime

DATE_PATTERNS = [
    re.compile(r"(\d{4})-(\d{1,2})-(\d{1,2})(?:\s+(\d{1,2}):(\d{1,2}))?"),
    re.compile(r"(\d{4})/(\d{1,2})/(\d{1,2})(?:\s+(\d{1,2}):(\d{1,2}))?"),
    re.compile(r"(\d{4})年(\d{1,2})月(\d{1,2})日(?:\s*(\d{1,2}):(\d{1,2}))?"),
]


def parse_absolute_datetime(text: str | None) -> str | None:
    text = normalize_space(text)
    if not text:
        return None

    for pattern in DATE_PATTERNS:
        match = pattern.search(text)
        if not match:
            continue

        year, month, day, hour, minute = match.groups()
        dt = datetime(
            int(year),
            int(month),
            int(day),
            int(hour or 0),
            int(minute or 0),
        )
        return dt.strftime("%Y-%m-%d %H:%M:%S")

    return None

from datetime import datetime, timedelta
import re


def parse_relative_datetime(text: str | None, now: datetime) -> str | None:
    text = normalize_space(text)
    if not text:
        return None

    if text == "刚刚":
        return now.strftime("%Y-%m-%d %H:%M:%S")

    match = re.search(r"(\d+)小时前", text)
    if match:
        dt = now - timedelta(hours=int(match.group(1)))
        return dt.strftime("%Y-%m-%d %H:%M:%S")

    match = re.search(r"昨天\s*(\d{1,2}):(\d{1,2})", text)
    if match:
        hour, minute = match.groups()
        dt = (now - timedelta(days=1)).replace(hour=int(hour), minute=int(minute), second=0, microsecond=0)
        return dt.strftime("%Y-%m-%d %H:%M:%S")

    return None

import re


def parse_amount(text: str | None) -> float | None:
    text = normalize_space(text)
    if not text:
        return None

    if "免费" in text:
        return 0.0
    if "面议" in text:
        return None

    match = re.search(r"([\d,]+(?:\.\d+)?)\s*(万)?", text)
    if not match:
        return None

    value = float(match.group(1).replace(",", ""))
    if match.group(2) == "万":
        value *= 10000

    return value

import re


def parse_tags(text: str | None) -> list[str]:
    text = normalize_space(text)
    if not text:
        return []

    parts = re.split(r"[,，/、#\s]+", text)
    tags = []
    seen = set()

    for part in parts:
        tag = part.strip()
        if not tag or tag in seen:
            continue
        seen.add(tag)
        tags.append(tag)

    return tags

def normalize_text(text: str | None) -> str | None:

    publish_time: str | None

    crawled_at: str


def clean_item(raw: RawItem) -> CleanItem | None:
    title = clean_title(raw.title)
    if not title:
        return None

    content = html_to_text(raw.content_html)
    price = clean_price(raw.price_text)
    publish_time = clean_publish_time(raw.publish_time_text, raw.crawled_at)
    tags = parse_tags(raw.tags_text)

    return CleanItem(
        url=raw.url,
        title=title,
        content=content,
        price=price,
        publish_time=publish_time,
        tags=tags,
        crawled_at=raw.crawled_at.strftime("%Y-%m-%d %H:%M:%S"),
    )

    return None

import logging

logger = logging.getLogger("cleaner")


def clean_batch(raw_items: list[RawItem]) -> list[CleanItem]:
    cleaned_items = []
    dropped_count = 0

    for raw in raw_items:
        item = clean_item(raw)
        if item is None:
            dropped_count += 1
            logger.warning("drop item url=%s reason=missing_required_title", raw.url)
            continue

        cleaned_items.append(item)

    logger.info(
        "clean batch total=%s cleaned=%s dropped=%s",
        len(raw_items),
        len(cleaned_items),
        dropped_count,
    )
    return cleaned_items

二十一、常见错误写法

1. 不保留原始字段

只保存清洗结果，一旦清洗错了很难回溯。

建议保存 raw 和 clean。

2. 所有字段共用一个清洗函数

标题、正文、价格、日期、标签的清洗规则不同。

不要一个 clean_text 解决所有问题。

3. 把缺失值都变成空字符串

空字符串和 None 语义不同。

None 更适合表示缺失。

空字符串可能只是清洗后的文本为空。

4. 把特殊语义误清洗

例如：

1
2
3
4

免费 -> 0。
面议 -> None 或 special_status。
未知 -> None。
售罄 -> stock=0 或 status=sold_out。

要根据业务字段处理。

5. 没有数据质量指标

如果不记录清洗失败率，页面改版后可能很久才发现。

至少要记录：

1
2
3
4
5

总数。
成功数。
丢弃数。
字段缺失数。
校验失败数。

二十二、面试表达

如果面试官问：

1

爬虫拿到数据后，你会怎么清洗？

可以这样回答：

我会先保留原始字段，再按字段类型做清洗。比如标题和摘要会清理空白，正文会去掉 script、style、广告和推荐块并保留段落，价格会去掉货币符号和单位后转成数值，日期会统一成标准时间格式，标签会拆分、去重和归一化。清洗后不会直接入库，而是用 Pydantic 或 JSON Schema 做字段校验，并记录清洗失败原因和数据质量指标。

如果问：

1

如何处理字段缺失？

可以这样回答：

我会区分必填字段和可选字段。可选字段缺失可以记为 None，必填字段缺失则不能直接入库，需要记录失败原因。对于“暂无”“未知”“–”这类占位符，会统一转换为 None，但也会根据字段语义处理特殊值，比如价格中的“免费”应该是 0，而“面议”不应该简单变成 0。

如果问：

1

清洗规则变了怎么办？

可以这样回答：

我会保留原始数据和清洗版本。规则变更时，通过样例测试验证新规则，再对受影响的数据重新清洗。线上会观察清洗成功率、字段缺失率和 Schema 校验失败率，避免规则更新引入新的数据质量问题。

如果问：

1

LLM 能不能替代数据清洗规则？

可以这样回答：

不能完全替代。空白清理、日期归一化、价格转换、缺失值处理这类确定性任务更适合规则，速度快、成本低、可测试。LLM 更适合语义复杂的非结构化抽取，比如从商品描述中抽取属性、从正文中生成摘要或解释清洗失败原因。工程上应该规则优先，LLM 补充，最后统一做 Schema 校验和必要的人工复核。

二十三、总结

本文讲了非结构化网页数据清洗的工程方法。

核心结论包括：

  • 爬虫提取到字段不等于数据已经可用，清洗是入库前的关键步骤。
  • 清洗前要尽量保留原始数据，方便回溯和重新处理。
  • 标题、正文、价格、日期、标签等字段应该使用不同清洗策略。
  • HTML 片段要先移除 script、style 等无关标签，再提取正文。
  • 正文清洗要先定位主体内容，不要直接对整页 get_text()。
  • 缺失值要统一处理，但特殊语义要按业务区分。
  • 日期、金额、单位要归一化成可计算、可查询的格式。
  • 清洗后必须经过 Schema 校验，不能直接入库。
  • 清洗层要记录失败率、缺失率、校验错误等数据质量指标。
  • 清洗规则应该可以版本化，支持回溯和重跑。
  • LLM 适合语义抽取和诊断辅助，但不能替代所有确定性规则。
