动态规划进阶：乘积最大子数组——如何化‘负’为‘正’？

2026-04-01 16:36
阅读时长: 3 分钟

在 [LeetCode 152. 乘积最大子数组] 中，我们要找出一个数组中乘积最大的连续子数组。相比于求“最大和”，这道题的逻辑要复杂得多，因为数字正负号的交替会让结果发生剧烈震荡。

一、 核心思想：未雨绸缪，双状态维护

在求“最大和”时，我们只需要记得“之前最大的和是多少”。但在求“最大乘积”时，情况变了：

  • 如果当前数是正数，我们希望乘上之前的最大值。
  • 如果当前数是负数，我们反而希望乘上之前的最小值（负负得正）。

阿彪直觉：我们不仅要记住“最高峰”，还要记住“最低谷”。因为在负数面前，最低谷就是下一刻翻身的最高峰。

二、 解题方法：动态规划 (DP)

我们定义两个 DP 数组：

  1. cur_max[i]：以第 $i$ 个数结尾的子数组的最大乘积。
  2. cur_min[i]：以第 $i$ 个数结尾的子数组的最小乘积。

状态转移方程

对于每个位置 $i$，我们有三个候选答案：

  • 拿当前数乘上之前的最大值：cur_max[i-1] * nums[i]
  • 拿当前数乘上之前的最小值：cur_min[i-1] * nums[i]
  • 谁也不乘，从自己开始：nums[i]
$$cur\_max[i] = \max(前两项乘积, nums[i])$$

$$cur\_min[i] = \min(前两项乘积, nums[i])$$

三、 举例说明：nums = [2, 3, -2, -4]

  1. i = 0 (2):
    • max = 2, min = 2
  2. i = 1 (3):
    • 候选：$2 \times 3=6, 2 \times 3=6, 3$。
    • max = 6, min = 3
  3. i = 2 (-2):
    • 候选：$6 \times -2=-12, 3 \times -2=-6, -2$。
    • max = -2 (自立门户), min = -12
  4. i = 3 (-4):
    • 候选：$-2 \times -4=8, -12 \times -4=48, -4$。
    • 奇迹发生！ 乘上之前的最小值 -12，得到了 48。
    • max = 48, min = -4

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        n = len(nums)
        # cur_max[i] 记录以 nums[i] 结尾的最大乘积
        cur_max = [0] * n
        cur_min = [0] * n
        
        cur_max[0] = cur_min[0] = nums[0]
        
        for i in range(1, n):
            # 三者取其大/小
            cur_max[i] = max(cur_max[i-1]*nums[i], cur_min[i-1]*nums[i], nums[i])
            cur_min[i] = min(cur_max[i-1]*nums[i], cur_min[i-1]*nums[i], nums[i])
            
        return max(cur_max)

优化版：滚动变量 (O(1) 空间)

既然 $i$ 只依赖 $i-1$，我们不需要数组，两个变量足矣。

class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        res = cur_max = cur_min = nums[0]
        
        for i in range(1, len(nums)):
            n = nums[i]
            # 提前存下 cur_max，防止计算 min 时已被修改
            temp_max = cur_max
            cur_max = max(n, temp_max * n, cur_min * n)
            cur_min = min(n, temp_max * n, cur_min * n)
            res = max(res, cur_max)
            
        return res

五 : 总结与深度反思 [抱拳]

  1. 为什么需要 nums[i] 参与比较？ 这代表了“重新开始”。如果之前的乘积很小（比如 0.1），而当前数很大（比如 100），我们宁愿舍弃过去，从当前数重新起步。
  2. 负数带来的启示： 在算法中，极端的负面状态往往蕴含着转机。本题通过维护最小值，完美捕捉了负负得正的机会。
  3. 时空复杂度：
    • 时间：$O(N)$。只需线性扫描一遍。
    • 空间：$O(N)$ 或 $O(1)$。
