单调栈入门：深度拆解『每日温度』的寻找之美

2026-03-27 18:00
阅读时长: 3 分钟

LeetCode 739. 每日温度 要求我们计算：对于每一天，还要再等多久才能等到一个更高的气温。如果未来没有更高的，则填 0。

这道题是掌握单调栈这一进阶数据结构的必经之路。

1. 暴力解法：一眼望穿 (O(n²))

最直观的想法是：对于每一天，我都向后遍历，直到找到一个比今天高的温度。

  • 逻辑：双重循环。
  • 复杂度：$O(n^2)$。
  • 评价：当数据量达到 $10^5$ 时，计算量高达 100 亿次，必超时。我们需要一种“只扫一遍”就能记住之前状态的办法。

2. 核心思想：为什么用单调栈？

单调栈的精髓在于：“暂时处理不了的，先存起来；一旦能处理了，成批处理。”

想象你在排队：

  • 如果新来的人（今天的温度）比你矮，你只能继续等。
  • 如果新来的人比你高，恭喜你，你的等待结束了！

为了方便计算“等了几天”，我们栈里存的不只是温度，还得存下标（Index）。

3. 从左向右遍历（阿彪的代码逻辑）

这是最符合人类直觉的写法：“新元素去解救旧元素”。

🚀 逻辑拆解

  1. 遍历每一天。
  2. While 循环：只要当前的温度 tem 比栈顶的温度高：
    • 说明栈顶那天的“等待”结束了。
    • 弹出栈顶，计算日期差：当前索引 - 栈顶索引。
  3. 将当前天压入栈中（因为它还在等属于它的那个更高温）。

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        res = [0] * len(temperatures)
        stack = [] # 栈里存下标
        
        for i, t in enumerate(temperatures):
            # 如果今天比栈顶那天暖和
            while stack and t > temperatures[stack[-1]]:
                prev_index = stack.pop()
                res[prev_index] = i - prev_index
            # 无论如何，今天都要入栈（寻找属于它的未来）
            stack.append(i)
        return res

4. 从右向左遍历（逆向思维）

有的同学喜欢倒着走：“从未来看现在”。

🚀 逻辑拆解

  1. 从最后一天往第一天走。
  2. While 循环：如果栈顶温度比今天矮（或相等），那它永远不可能是今天左边那些天的“第一个更高温”，因为它被今天挡住了。直接踢走（Pop）。
  3. 此时栈顶就是今天右边第一个比今天暖和的人。
  4. 将今天压入栈，作为左边天的参考。

class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        res = [0] * n
        stack = [] # 存下标
        
        for i in range(n - 1, -1, -1):
            # 踢走比今天矮的“未来”
            while stack and temperatures[i] >= temperatures[stack[-1]]:
                stack.pop()
            # 剩下的栈顶就是最近的更高温
            if stack:
                res[i] = stack[-1] - i
            stack.append(i)
        return res

5. 举例：[73, 74, 71, 72]

我们按“从左向右”走一遍：

  1. i=0, t=73: 栈空，stack=[0]。
  2. i=1, t=74: 74 > 73。弹出 0，res[0] = 1-0=1。stack=[1]。
  3. i=2, t=71: 71 < 74。入栈，stack=[1, 2]。
  4. i=3, t=72: 72 > 71。弹出 2，res[2] = 3-2=1。
    • 继续比较：72 < 74。停止。
    • 入栈，stack=[1, 3]。
  5. 结束：栈里剩下的 1 和 3 没被解救，res 对应位置保持 0。

6. 阿彪的面试避坑指南 [抱拳]

① 为什么叫“单调栈”？

因为在这个过程中，栈里的元素（对应的温度）始终保持着单调递减。一旦出现一个大的，就会把小的破坏掉并弹出。

② 什么时候用从左到右？

如果题目倾向于“寻找之后第一个…”，通常从左到右比较顺手。

③ 复杂度

  • 时间复杂度：$O(n)$。每个元素进栈一次，出栈一次。
  • 空间复杂度：$O(n)$。最坏情况下（温度递减），栈会存下所有元素。
