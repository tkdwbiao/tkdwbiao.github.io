左右包抄：彻底攻克『除自身以外数组的乘积』

2026-03-30 17:00
阅读时长: 3 分钟

在 LeetCode 238. 除自身以外数组的乘积 中，题目有一个非常严苛的约束：不能使用除法，且时间复杂度必须为 $O(n)$。

如果没有除法，我们该如何高效地拿到除自己以外的所有数乘积呢？

1. 核心思想：化整为零，左右包抄

想象一下，对于数组中的任意一个位置 $i$，除了它自己以外的所有元素乘积，可以拆解为两部分：

  1. $i$ 左侧所有元素的乘积（前缀积）。
  2. $i$ 右侧所有元素的乘积（后缀积）。

最终结果就是：结果[i] = 左积[i] × 右积[i]。

“既然不能直接除掉自己，那就把左右两边的力量合起来围攻自己。”

2. 解题方法：构造前缀与后缀数组

我们通过两次遍历来分别构建这两股“力量”：

  1. 第一次遍历（从左往右）：计算每个元素左边的乘积。
  2. 第二次遍历（从右往左）：计算每个元素右边的乘积。
  3. 最后合并：对应位置相乘。

class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        
        # 1. 初始化前缀积数组，pre[i] 表示 nums[i] 左侧所有数的乘积
        pre = [1] * n
        for i in range(1, n):
            # 当前位置的左积 = 上一个位置的左积 * 上一个位置的数值
            pre[i] = pre[i - 1] * nums[i - 1]

        # 2. 初始化后缀积数组，suf[i] 表示 nums[i] 右侧所有数的乘积
        suf = [1] * n
        for i in range(n - 2, -1, -1):
            # 当前位置的右积 = 下一个位置的右积 * 下一个位置的数值
            suf[i] = suf[i + 1] * nums[i + 1]
            
        # 3. 利用 zip 将前缀和后缀对应位置相乘，得到最终结果
        return [p * s for p, s in zip(pre, suf)]

4. 算法回顾与深度反思

① 为什么不能用除法？

如果数组中没有 0，除法确实很快（总乘积 / nums[i]）。但一旦数组中出现 0，除法就会报错（DivisionByZero）。

  • 如果有 1 个 0，除 0 位置外其他全为 0。
  • 如果有 2 个及以上的 0，结果全为 0。 前缀/后缀积法完美规避了 0 的特殊判断，逻辑统一。

② 复杂度分析

  • 时间复杂度：$O(n)$。我们进行了三次线性遍历（左积、右积、合并），常数项忽略后为 $O(n)$。
  • 空间复杂度：$O(n)$。我们额外使用了 pre 和 suf 两个数组。

③ 进一步优化的思考（阿彪进阶）

面试官可能会问：“能不能用 $O(1)$ 的额外空间（输出数组不计入）完成？” 反思建议：

  1. 先把结果存入 res 数组充当 pre。
  2. 然后用一个变量 R 实时维护当前的后缀积，从右往左扫，直接在 res 上做乘法。 这样就能省掉 pre 和 suf 两个数组的开销。

5. 阿彪的面试避坑指南 [抱拳]

  1. 边界初始化：pre[0] 和 suf[n-1] 必须初始化为 1，因为它们的左边或右边没有元素，乘积的贡献位是单位 1。
  2. 循环范围：
    • 前缀积从 1 开始，依赖 i-1。
    • 后缀积从 n-2 开始，依赖 i+1。
  3. 理解 zip：在 Python 中使用 zip 配合列表推导式是非常 Pythonic 的写法，能给面试官留下良好的语言熟悉度印象。

掌握了“左右包抄”的思想，你会发现它和“前缀和”有着异曲同工之妙。阿彪祝大家逻辑永不断链！
