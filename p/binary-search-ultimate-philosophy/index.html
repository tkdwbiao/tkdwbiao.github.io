二分查找大圆满：从“万能模板”到指针错位的哲学

2026-03-24 13:33
阅读时长: 3 分钟

二分查找（Binary Search）在很多人眼里只是 $O(\log n)$ 的快速查找，但在高手眼中，它是一门 “挤压区间” 的艺术。

今天阿彪带大家把二分查找彻底打通，建立一套通杀所有变体的万能思维模型。

1. 核心模型：红蓝染色法

二分查找的本质不是在找一个数，而是在把一个有序世界切分成两个颜色：

  • 左半区（红色）：不满足条件的“旧世界”。
  • 右半区（蓝色）：满足条件的“新世界”。

def universal_binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        
        if 判定为红色区域: # 比如 nums[mid] < target
            left = mid + 1
        else: # 判定为蓝色区域
            right = mid - 1
            
    # 💥 重点：循环结束时 left 与 right 的“停靠哲学”
    return left, right

2. 指针错位的哲学：返回谁？

这是阿彪近期悟出的最强心法。当 while left <= right 结束时，两个指针发生了 “擦肩而过”，它们定义了世界的边界：

  • left：永远停在 “新世界（蓝色）的第一个人”。
  • right：永远停在 “旧世界（红色）的最后一个人”。

3. 实战：破解旋转数组

旋转数组（如 [4,5,6,7,0,1,2]）是二分查找的最佳练兵场。

场景 A：寻找最小值（找新世界的开头）

我们以末尾元素 nums[-1] 为基准，判定当前是否还在“左侧高坡”：

def findMin(nums):
    l, r = 0, len(nums) - 1
    target = nums[-1]
    while l <= r:
        mid = l + (r - l) // 2
        if nums[mid] > target: # 还在高坡（红色）
            l = mid + 1
        else: # 已经进低坡了（蓝色）
            r = mid - 1
    return nums[l] # 返回新世界的开头

场景 B：寻找最大值（找旧世界的结尾）

我们以开头元素 nums[0] 为基准，寻找第一段斜坡的终点：

def findMax(nums):
    l, r = 0, len(nums) - 1
    target = nums[0]
    while l <= r:
        mid = l + (r - l) // 2
        if nums[mid] >= target: # 还在第一段坡（红色）
            l = mid + 1
        else: # 掉下去了（蓝色）
            r = mid - 1
    return nums[r] # 返回旧世界的结尾

4. 阿彪的面试避坑笔记 [抱拳]

① 为什么不用 while left < right？

虽然 left < right 在找最小值时很常用，但它需要判断 right = mid 还是 right = mid - 1。 阿彪建议：死守 left <= right。配合 left = mid + 1 和 right = mid - 1，你永远不需要担心死循环，逻辑极其稳健。

② 坐标转换的黑科技

在二维矩阵搜索中，记住这个公式：

  • Row = Index // Cols
  • Col = Index % Cols 这能让你像操作一维数组一样操作二维矩阵。

③ 防止溢出

永远写 mid = left + (right - left) // 2 而不是 (left + right) // 2。虽然在 Python 里没区别，但这是专业算法工程师的肌肉记忆。

总结：阿彪的浪漫二分观

“左右指针的相遇不是结束，而是两个世界的交接。”

二分查找不仅是搜索。它教会了我们：只要具备“二段性”（一侧满足，一侧不满足），我们就能在 $O(\log n)$ 的时间内，将庞大的未知世界挤压到两个相邻的指针之间。
