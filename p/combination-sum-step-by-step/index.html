组合总和：从暴力回溯到剪枝优化的进阶之路

2026-04-01 15:10
阅读时长: 3 分钟

在 LeetCode 39. 组合总和 中，给定一个无重复元素的数组 candidates 和一个目标数 target，找出所有可以使数字和为 target 的组合。

这道题是理解回溯算法中“重复利用”与“剪枝优化”的最佳教材。

一、 基础阶段：直觉驱动的暴力回溯

1. 思想 (Idea)

回溯算法本质上是在一棵决策树上进行深度优先搜索（DFS）。

  • 去重逻辑：为了避免搜出 [2, 3] 和 [3, 2] 这种重复组合，我们规定一个“起跑线” start。每次只能从当前位置或往后选，不能回头。
  • 重复利用：因为题目说可以无限次使用同一个数，所以递归进入下一层时，起跑线依然设为 i，而不是 i + 1。

2. 过程 (Process)

  1. 从第 0 个数开始尝试。
  2. 每次把数加进 path。
  3. 用 sum(path) 检查：
    • 等于 target：找到一个答案，存入 res。
    • 大于 target：此路不通，直接回头。
  4. 撤销选择（pop），换下一个数试试。

class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        res = []
        path = []

        def dfs(start):
            # 终止条件
            current_sum = sum(path)
            if current_sum == target:
                res.append(path[:])
                return 
            if current_sum > target:
                return

            for i in range(start, len(candidates)):
                path.append(candidates[i])
                # 递归：传 i 代表允许重复使用当前数字
                dfs(i)
                # 回溯：清理现场
                path.pop()

        dfs(0)
        return res

二、 优化阶段：性能与空间的压榨

1. 思想 (Idea)

基础版虽然能过，但有两个明显的性能瓶颈：

  • 重复求和：每次都 sum(path) 太慢了，我们可以用减法，把 target 往下传。
  • 盲目搜索：如果数组是有序的，当前数字已经太大了，后面的数字肯定也大，没必要再进递归了。

2. 过程 (Process)

  1. 预处理：先对 candidates 进行排序。
  2. 参数化状态：递归函数改为 dfs(start, remain)，remain 代表距离目标的缺口。
  3. 剪枝 (Pruning)：在 for 循环中，如果 candidates[i] > remain，直接 break 掉整个循环。

class Solution:
    def combinationSum(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort() # 排序是剪枝的前提
        res = []
        path = []

        def dfs(start, remain):
            if remain == 0:
                res.append(path[:])
                return 

            for i in range(start, len(candidates)):
                # 【核心剪枝】
                if candidates[i] > remain:
                    break # 后面的数更大，不用看了
                
                path.append(candidates[i])
                dfs(i, remain - candidates[i])
                path.pop()

        dfs(0, target)
        return res

三、 阿彪的深度总结 [抱拳]

1. 复杂度对比

维度基础版优化版
单次判断$O(K)$ (使用 sum)$O(1)$ (使用变量)
搜索空间全力搜索修剪后的搜索树
面试评价逻辑正确，功底一般专业、严谨、效率高

2. 核心避坑指南

  • dfs(i) vs dfs(i+1)：这是区分“可重复选”和“不可重复选”的关键开关。
  • 切片副本 path[:]：回溯题的通病，不加切片最后 res 里的结果都会被 pop 成空列表。
  • 排序的收益：在回溯中，排序往往不是为了排序本身，而是为了给 break 创造逻辑条件。
