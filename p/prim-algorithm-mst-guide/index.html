图论精髓：Prim 算法——像‘滚雪球’一样构建最小生成树

2026-04-14 17:26
阅读时长: 3 分钟

最小生成树（Minimum Spanning Tree, MST）是图论中的经典问题：如何在保证所有节点连通的前提下，使边的总权值和最小？今天阿彪带大家拆解 Prim 算法，掌握这种“以点扩面”的贪心艺术。

一、 核心思想：贪心的“修路计”

Prim 算法的逻辑非常直观，可以类比为城市电网铺设：

  1. 起点：我们先随机选择一个城市作为电网的中心。
  2. 观察：看看所有“已通电城市”连接“未通电城市”的所有电缆中，哪一根最便宜（权值最小）。
  3. 扩张：把这根最便宜的电缆铺好，让新城市通电。
  4. 循环：重复这个过程，直到所有城市都连进电网。

“Prim 的精髓：始终盯着离‘组织’最近的那个边缘人。”

二、 解题方法：选、标、改三部曲

为了实现这个过程，我们需要两个核心工具：

  • minDist 数组：记录每个节点距离当前“生成树集合”的最短距离。
  • visited 数组：标记节点是否已经进入了生成树。

🚀 算法三步走：

  1. 选 (Select)：在所有 visited == False 的节点中，找一个 minDist 最小的节点 cur。
  2. 标 (Mark)：将 visited[cur] 设为 True，并将它的权值累加到总和中。
  3. 改 (Update)：遍历 cur 的所有邻居，如果“新节点到邻居的距离”比“邻居原本记录的 minDist”还要短，则更新它。

三、 举例说明：3个点，3条边

假设边为：(1,2,1), (2,3,2), (1,3,4)

  1. 初始化：minDist = [0, inf, inf] (选1为起点), visited = [F, F, F]。
  2. 第一轮：
    • 选：选中 1 号点。
    • 标：visited[1] = T, res = 0。
    • 改：1 的邻居有 2(距离1) 和 3(距离4)。更新 minDist[2]=1, minDist[3]=4。
  3. 第二轮：
    • 选：在 2 和 3 中选，2 的 minDist 小。选中 2。
    • 标：visited[2] = T, res = 0 + 1 = 1。
    • 改：2 的邻居有 3(距离2)。对比 3 原本的 minDist[3]=4，发现 2 更近！更新 minDist[3]=2。
  4. 第三轮：
    • 选：选中 3。
    • 标：visited[3] = T, res = 1 + 2 = 3。
  5. 结束：总权值为 3。

import sys

def prim():
    # 1. ACM 模式高效读取
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    n = int(input_data[0]) # 节点数
    m = int(input_data[1]) # 边数
    
    # 2. 初始化邻接矩阵，默认设为无穷大
    grid = [[float('inf')] * (n + 1) for _ in range(n + 1)]
    ptr = 2
    for _ in range(m):
        u, v, w = int(input_data[ptr]), int(input_data[ptr+1]), int(input_data[ptr+2])
        grid[u][v] = grid[v][u] = w # 无向图对称性
        ptr += 3

    # 3. 准备核心数组
    minDist = [float('inf')] * (n + 1)
    visited = [False] * (n + 1)

    # 4. 起点初始化（选 1 号点）
    minDist[1] = 0
    total_weight = 0

    # 5. 核心循环：总共需要加入 n 个节点
    for _ in range(n):
        # --- 第一步：选 ---
        cur = -1
        min_val = float('inf')
        for i in range(1, n + 1):
            if not visited[i] and minDist[i] < min_val:
                min_val = minDist[i]
                cur = i
        
        if cur == -1: break # 如果图不连通
            
        # --- 第二步：标 ---
        visited[cur] = True
        total_weight += min_val
        
        # --- 第三步：改 ---
        for i in range(1, n + 1):
            # 如果 i 还没入树，且通过新成员 cur 到达 i 的距离更近
            if not visited[i] and grid[cur][i] < minDist[i]:
                minDist[i] = grid[cur][i]

    # 6. 结果输出
    print(total_weight)

if __name__ == "__main__":
    prim()

五、 阿彪的深度反思 [抱拳]

1. 为什么初始化用 inf？

在求“最小”逻辑中，0 是极具干扰性的背景板。如果初始化为 0，min(0, 5) 永远是 0，导致状态无法更新。

2. Prim vs Dijkstra 的微妙区别

很多同学会搞混这两个算法。其实它们只有“改（Update）”这一步逻辑不同：

  • Prim：minDist[i] = grid[cur][i]。看的是点到生成树集合的距离。
  • Dijkstra：minDist[i] = minDist[cur] + grid[cur][i]。看的是点到起点的累加距离。

3. 时间复杂度

本写法为 $O(N^2)$，适用于稠密图（边很多）。如果点数达到万级，则需要使用“堆优化”版的 Prim，将复杂度降为 $O(M \log N)$。

六、 同类思想题推荐

掌握了最小生成树，建议挑战：

  1. [卡码网 53. 寻宝]：本题的标准练习。
  2. [LeetCode 1584. 连接所有点的最小费用]：曼哈顿距离下的 MST。
  3. [Kruskal 算法]：另一种基于“并查集”的 MST 实现，适合稀疏图。
