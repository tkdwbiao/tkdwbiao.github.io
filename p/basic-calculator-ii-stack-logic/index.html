算法实战：手写基本计算器——栈与优先级的博弈

2026-04-14 16:30
阅读时长: 3 分钟

在 [LeetCode 227. 基本计算器 II] 中，我们需要处理加减乘除。这道题是考察栈（Stack）以及运算符优先级的经典题目。

阿彪在练习时发现，很多同学会纠结于如何处理 * 和 / 的高优先级。其实，只要换个思路，问题会变得非常简单。

一、 核心思想：延迟结算

在处理表达式时，我们不能一看到数字就操作。 阿彪的逻辑口诀：

“遇到数字先拼凑，遇到符号看前驱。加减直接进库房，乘除出库算完回。”

我们要维护一个变量 pre_sign。当我们遇到一个新的符号时，说明上一个数字已经完整了，此时我们根据 pre_sign 来决定怎么把这个数字放入栈中。

二、 算法过程拆解

以 3 + 2 * 2 为例：

  1. 初始：stack = [], num = 0, pre_sign = '+'。
  2. 读到 3：num = 3。
  3. 读到 +：
    • 触发结算：pre_sign 是 +，所以把 3 入栈。stack = [3]。
    • 更新：pre_sign = '+', num = 0。
  4. 读到 2：num = 2。
  5. **读到 * **：
    • 触发结算：pre_sign 是 +，把 2 入栈。stack = [3, 2]。
    • 更新：pre_sign = '*', num = 0。
  6. 读到最后一个 2：num = 2。
  7. 遍历结束：
    • 触发结算：pre_sign 是 *。弹出栈顶 2，计算 2 * 2 = 4，压回栈。
    • stack = [3, 4]。
  8. 最后求和：3 + 4 = 7。

三、 阿彪的避坑心得 [抱拳]

1. 多位数字的处理

千万不要以为 int(c) 就能搞定。一定要用 num = num * 10 + int(c) 来处理连续的数字字符。

2. 加减法的先后顺序

为什么最后可以 sum(stack)？ 因为我们在遇到 - 时，存入的是负数。这把减法转换成了加法，完美符合加法交换律，规避了从右往左算的逻辑错误。

3. Python 的除法坑

Python 的 // 是向下取整（Floor Division）。

  • int(-3 / 2) 结果是 -1（题目要求）。
  • -3 // 2 结果是 -2。 面试建议：涉及负数除法取整，统一用 int(a / b)。

四、 复杂度分析

  • 时间复杂度：$O(n)$。字符串只被扫描了一遍。
  • 空间复杂度：$O(n)$。最坏情况下，栈存储了大约一半的数字。

掌握了“ pre_sign”结算机制，你就能在面试中稳如泰山地写出任何模拟计算器。阿彪加油！

输入：s = “3+2*2” 计算：3 + 2 * 2 = 7 输出：7

class Solution:
    def calculate(self, s: str) -> int:
        stack = []
        num = 0
        pre_sign = '+' # 记录数字左边的符号
        
        for i in range(len(s)):
            c = s[i]
            
            # 1. 如果是数字，拼起来
            if c.isdigit():
                num = num * 10 + int(c)
            
            # 2. 如果是符号，或者到了字符串最后一位（必须结算最后一个数字）
            if (not c.isdigit() and c != ' ') or i == len(s) - 1:
                if pre_sign == '+':
                    stack.append(num)
                elif pre_sign == '-':
                    stack.append(-num) # 减法变负数入栈
                elif pre_sign == '*':
                    # 乘除法优先级高，直接和栈顶结算
                    stack.append(stack.pop() * num)
                elif pre_sign == '/':
                    # Python 的 // 是向下取整，题目要求向 0 取整
                    # 所以用 int(prev / num)
                    prev = stack.pop()
                    stack.append(int(prev / num))
                
                # 3. 结算完后，更新符号，数字清零
                pre_sign = c
                num = 0
        
        # 4. 最后栈里剩下的全是加法关系，直接求和
        return sum(stack)
