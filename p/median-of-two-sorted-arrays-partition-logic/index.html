征服 LeetCode 04：寻找中位数的终极奥义 —— 黄金切分线

2026-03-24 18:00
阅读时长: 4 分钟

LeetCode 4. 寻找两个正序数组的中位数 被公认为二分查找最难的变体。它的 Hard 不在于代码量，而在于如何打破“合并数组”的思维定式，在对数时间内定位目标。

今天阿彪带大家拆解这道题的底层物理模型：黄金切分线。

1. 阿彪的思维演进：从 $O(mn)$ 到 $O(\log)$

❌ 误区：逐个插入

我最初的想法是：利用二分查找定位 nums2 中的元素该插入 nums1 的哪个位置，然后调用 list.insert()。

  • 痛点：insert() 操作是 $O(n)$ 的。如果有 $m$ 个元素要插入，总复杂度是 $O(m \times n)$。
  • 面试官的底线：题目要求 $O(\log(m+n))$。这意味着我们连数组都不能完整遍历，只能用二分“跳着找”。

2. 核心物理模型：黄金切分线 (Partition Line)

中位数的本质是什么？它是把一个有序序列切成等长两半的那根线。

现在有两个数组 $A$ 和 $B$，我们要找一根垂直切下去的线，把它们各自切成两半：

  • $A$ 被切成：A_left | A_right（左边 $i$ 个元素）
  • $B$ 被切成：B_left | B_right（左边 $j$ 个元素）

1. 必须满足的两个硬指标：

  1. 数量平衡：左边总数 = 右边总数（或多一个）。

    • 公式：$i + j = (m + n + 1) // 2$
    • 阿彪感悟：只要确定了 $i$，$j$ 就是自动算出来的。我们只需要在短数组上二分查找 $i$。

  2. 交叉小于等于（核心逻辑）：

    • 线左边的所有人，都要小于线右边的所有人。
    • 由于数组本身有序，我们只需要盯住交叉点：
      • $A[i-1] \le B[j]$ （$A$ 的左大 $\le$ $B$ 的右小）
      • $B[j-1] \le A[i]$ （$B$ 的左大 $\le$ $A$ 的右小）

“我们二分查找的不是数值，而是这根能让左右达成平衡的‘切分线’。”

2. 举个例子：动图级拆解

假设： nums1 = [1, 3, 5, 7] ($m=4$) nums2 = [2, 4, 8, 9, 10] ($n=5$) 总长度 $= 9$。我们要找左半部分有 $(9+1)//2 = 5$ 个元素的位置。

第一轮二分：

  • 对 nums1 取中点：$i = 2$。
  • 根据公式算 $j$：$j = 5 - 2 = 3$。
  • 切分情况：
    • nums1: [1, 3 | 5, 7] -> 左大 $A[i-1]=3$，右小 $A[i]=5$
    • nums2: [2, 4, 8 | 9, 10] -> 左大 $B[j-1]=8$，右小 $B[j]=9$
  • 检查交叉：
    • $3 \le 9$ (成立)
    • $8 \le 5$ (不成立！ $B$ 的左边太大了)
  • 结论：$i$ 太小了，导致 $B$ 拿了太多。我们需要让 $i$ 变大（右移），这样 $j$ 就会自动变小。

第二轮二分（$i$ 往右找）：

  • …重复直到找到满足交叉条件的 $i$ 和 $j$。

3. 算法实现：边界的“哨兵”艺术

在二分过程中，如果切线移到了最左边（$i=0$）或最右边（$i=m$），直接取值会报错。阿彪教你一招：引入正负无穷大。

  • 如果左边没数了，最大值设为 -float('inf')。
  • 如果右边没数了，最小值设为 float('inf')。。

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # 1. 确保 nums1 是短的，优化效率且防止 j 算出负数
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
            
        m, n = len(nums1), len(nums2)
        left, right = 0, m
        half_len = (m + n + 1) // 2
        
        while left <= right:
            i = (left + right) // 2 # A 的切点
            j = half_len - i        # B 的切点
            
            # 2. 确定四个关键边界值
            A_left_max = nums1[i-1] if i > 0 else -float('inf')
            A_right_min = nums1[i] if i < m else float('inf')
            B_left_max = nums2[j-1] if j > 0 else -float('inf')
            B_right_min = nums2[j] if j < n else float('inf')
            
            # 3. 验证切分线是否合法
            if A_left_max <= B_right_min and B_left_max <= A_right_min:
                # 完美切分！
                if (m + n) % 2 == 1:
                    return float(max(A_left_max, B_left_max))
                else:
                    return (max(A_left_max, B_left_max) + min(A_right_min, B_right_min)) / 2.0
            
            elif A_left_max > B_right_min:
                # A 的左边太大了，切线左移
                right = i - 1
            else:
                # A 的左边太小了，切线右移
                left = i + 1

4. 为什么这个方案是 $O(\log(\min(m, n)))$？

  1. 我们只对短数组进行二分。
  2. 每次比较只需要 $O(1)$ 的时间（只看四个相邻元素）。
  3. 空间复杂度 $O(1)$，只用了几个指针。

5. 阿彪的面试避坑笔记 [抱拳]

① 为什么不能对长数组二分？

如果 $m > n$，当你取 $i = m$ 时，$j = \text{half\_len} - m$ 可能会得到一个负数，直接导致索引溢出。

② 奇数情况下的 half_len

使用 (m + n + 1) // 2 保证了在总数为奇数时，左半部分会比右半部分多出恰好一个元素。此时，中位数就是 max(左边两个最大值)。这个细节能省去大量的 if-else。

③ 面试话术

“面试官，这道题的难点在于如何在不合并数据的前提下实现 $O(\log)$ 级搜索。我的思路是将问题转化为寻找两个数组间的平衡切分点。通过在较短数组上执行二分查找，并实时校验交叉边界的单调性，我可以精准锁定中位数的位置。”

从暴力插入到切分平衡，这不仅是代码的优化，更是算法思维从‘线性’到‘对数’的跨越。阿彪祝大家早日攻克 Hard，拿下 Offer！
