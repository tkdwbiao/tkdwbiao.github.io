从递归到一维 DP：算法进化的三重境界

2026-03-27 22:30
阅读时长: 3 分钟

动态规划（Dynamic Programming）听起来很高大上，但它的本质只有一句话：“记住过去，推导未来。”

今天阿彪带大家通过一个经典案例，拆解算法如何从“自顶向下”的递归，演变成“极致空间”的一维 DP。

一、 境界一：递归（自顶向下）

1. 核心思想

递归是 “大问题拆小问题”。

  • 出口 (Base Case)：最简单的情况是什么？（比如凑 0 元需要 0 个硬币）。
  • 递推 (Recursive Step)：想解决 $f(n)$，我先去问 $f(n-1)$。

2. 举例：爬楼梯 (n 级台阶，每次走 1 或 2 步)

想上到第 $n$ 级，要么是从 $n-1$ 级跨一步，要么是从 $n-2$ 级跨两步。 公式：$f(n) = f(n-1) + f(n-2)$

3. 代码实现

1
2
3

def climb(n):
    if n <= 2: return n
    return climb(n-1) + climb(n-2)

阿彪点评：这种写法有大量重复计算（比如算 $f(5)$ 会反复算 $f(2)$），时间复杂度是可怕的 $O(2^n)$。

二、 境界二：动态规划（自底向上）

1. 核心思想

与其在大问题里反复挣扎，不如 “从小做起”。

  • 填表法：准备一个数组 dp，从 dp[0] 开始填，一直填到 dp[n]。
  • 状态转移：每一格的值，都根据前面已经算好的格子推导出来。

2. 举例：同样的爬楼梯

我们开辟一个 dp 数组。

def climb_dp(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    # 1. 初始化（打地基）
    dp[1], dp[2] = 1, 2
    # 2. 顺序填表（推导未来）
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

阿彪点评：时间复杂度降到了 $O(n)$，但我们多花了一个 $O(n)$ 的数组空间。

三、 境界三：一维 DP / 滚动数组（极致优化）

1. 核心思想

“过河拆桥”。 观察发现：算 dp[i] 时，我们只用到了 dp[i-1] 和 dp[i-2]。那么 dp[i-3] 之前的那些数据，其实已经没用了。

  • 空间压缩：我们不需要整个数组，只需要几个变量来回倒手就行。

2. 遍历方向的玄学（阿彪必看）

这是背包问题里最难的一点：

  • 完全背包（正序遍历）：物品可以无限用。算 dp[j] 时，可以用“这一轮”刚算好的 dp[j-v]。
  • 0/1 背包（倒序遍历）：物品只能用一次。算 dp[j] 时，必须确保 dp[j-v] 还是“上一轮”留下的旧值。

3. 代码实现（以零钱兑换为例）

def coinChange(coins, amount):
    # 初始化：求最小，全填 inf
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    
    for coin in coins:
        # 正序遍历：完全背包特性，硬币无限复用
        for j in range(coin, amount + 1):
            dp[j] = min(dp[j], dp[j-coin] + 1)
            
    return dp[amount] if dp[amount] != float('inf') else -1

💡 阿彪的总结笔记 [抱拳]

1. 三要素对比

维度递归二维 DP一维 DP
思维方向自顶向下（拆解）自底向上（构建）自底向上（精简）
空间开销$O(n)$ (系统栈)$O(n^2)$ 或 $O(n)$$O(1)$ 或 $O(W)$
代码难度简单（如诗优美）一般（逻辑清晰）稍难（注意遍历方向）

2. 初始化口诀

  • 求最大：初始化全 0。
  • 求最小：初始化全 inf。
  • 凑 0 元：dp[0] = 0 是永远的基石。

3. 面试话术建议

“面试官，这道题的最优解是一维动态规划。我通过分析状态转移方程发现，当前状态仅依赖于前一个或前几个状态，因此我使用了滚动数组技术，将空间复杂度从 $O(n)$ 压缩至常数级。在遍历方向上，我根据题目‘物品可无限复用’的特点选择了正序遍历。”

阿彪寄语：算法的进化，就是对资源（时间、内存）利用率的极致追求。掌握了 DP，你就掌握了算法的灵魂！[加油]
