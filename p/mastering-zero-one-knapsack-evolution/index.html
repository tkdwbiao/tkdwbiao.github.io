从暴力回溯到极致压缩：深度拆解 0/1 背包问题的四重境界

2026-03-25 12:00
阅读时长: 4 分钟

0/1 背包问题（0/1 Knapsack Problem）是算法面试中最重要的动态规划范式。之所以称为“0/1”，是因为每件物品只有一件：要么不选（0），要么选（1）。

今天阿彪带大家通过四种解法的演进，彻底看透背包问题的底层逻辑。

1. 境界一：暴力回溯（穷举思维）

核心思想： 对于每一件物品，我们只有两个选择：拿或者不拿。我们可以构建一棵满二叉树，遍历所有组合。

def knapsack_backtrack(weights, values, capacity):
    n = len(weights)
    self.max_val = 0

    def backtrack(index, current_weight, current_value):
        if index == n or current_weight >= capacity:
            self.max_val = max(self.max_val, current_value)
            return

        # 选择 1：不选当前物品，看下一个
        backtrack(index + 1, current_weight, current_value)

        # 选择 2：选当前物品（前提是装得下）
        if current_weight + weights[index] <= capacity:
            backtrack(index + 1, current_weight + weights[index], 
                      current_value + values[index])

    backtrack(0, 0, 0)
    return self.max_val
  • 复杂度分析：时间复杂度 $O(2^N)$。每多一件物品，计算量翻一倍。当 $N=30$ 时计算量就达 10 亿级，面试必挂。

2. 境界二：记忆化搜索（备忘录优化）

阿彪深度思考： 为什么暴力搜索这么慢？因为存在大量的重复子问题。只要 (当前下标, 剩余容量) 是一样的，后面能拿到的最大价值就是固定的。我们没必要重复计算，拿个本子记下来就行！

def knapsack_memo(weights, values, capacity):
    n = len(weights)
    memo = {} # 备忘录：{(index, remain): max_val}

    def dfs(index, remain):
        # 1. 终止条件
        if index == n or remain <= 0:
            return 0
        
        # 2. 查备忘录：算过就直接拿
        if (index, remain) in memo:
            return memo[(index, remain)]

        # 3. 逻辑决策
        # 不拿物品 i
        res = dfs(index + 1, remain)
        # 拿物品 i（前提是装得下）
        if remain >= weights[index]:
            res = max(res, values[index] + dfs(index + 1, remain - weights[index]))

        # 4. 存入备忘录
        memo[(index, remain)] = res
        return res

    return dfs(0, capacity)
  • 复杂度分析：时间复杂度降到了 $O(NW)$。因为不同的状态总数只有 $N \times W$ 个，每个状态只算一次。

3. 境界三：标准动态规划（二维矩阵）

核心思想： 记忆化搜索是“自顶向下”，而动态规划是 “自底向上”。我们定义 dp[i][j] 表示：从前 i 个物品里选，在容量为 j 时能拿到的最大价值。

🚀 状态转移方程

  1. 容量 $j$ 装不下物品 $i$：dp[i][j] = dp[i-1][j]
  2. 装得下：dp[i][j] = max(dp[i-1][j], dp[i-1][j - weight[i]] + value[i])

初始化：

  • 第一行 dp[0][j]：代表“一个东西都不选”。
    • 逻辑：没东西选，价值当然是 0。
  • 第一列 dp[i][0]：代表“口袋一点空间都没有”。
    • 逻辑：装不下东西，价值也是 0。

def knapsack_2d(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, capacity + 1):
            if j < weights[i-1]:
                dp[i][j] = dp[i-1][j]
            else:
                dp[i][j] = max(dp[i-1][j], 
                               dp[i-1][j - weights[i-1]] + values[i-1])
    return dp[n][capacity]
  • 复杂度分析：时间复杂度 $O(NW)$，空间复杂度 $O(NW)$。

4. 境界四：极致优化（一维滚动数组）

核心发现： 计算 dp[i] 时只用到 dp[i-1]。我们可以将二维矩阵压缩成一维数组 dp[j]。

“关键点：逆序遍历！为了保证更新 dp[j] 时，dp[j-w] 还是上一轮留下的值。”

def knapsack_1d(weights, values, capacity):
    dp = [0] * (capacity + 1)

    for i in range(len(weights)):
        # 必须从后往前遍历容量！
        for j in range(capacity, weights[i] - 1, -1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
            
    return dp[capacity]
  • 复杂度分析：时间 $O(NW)$，空间压缩到了 $O(W)$。

5. 阿彪的避坑与面试总结 [抱拳]

① 记忆化搜索 vs 动态规划

  • 记忆化搜索：自顶向下，只计算被访问到的状态，逻辑更符合直觉。
  • 动态规划：自底向上，循环迭代，效率更稳，且方便进行空间压缩。

② 为什么一维数组必须“逆序”？

  • 逆序：保证每个物品只被考虑一次，这是 0/1 背包。
  • 正序：物品可以被无限次放入，这是 完全背包。

③ 面试复述话术

“面试官，0/1 背包问题的优化经历了从指数级回溯到线性状态转移的过程。通过记忆化搜索，我们利用备忘录消除了冗余计算；随后通过动态规划将问题转为迭代实现，并利用滚动数组技巧将空间复杂度由 $O(NW)$ 极致压缩至 $O(W)$，从而在有限的内存下处理更大规模的数据。”

6. 🚩 阿彪的避坑红线：初始化的“玄学”

很多同学问：为什么我的代码和题解一模一样，结果却差之千里？ 请检查你的 dp[0]。

  • 如果求的是 “最大价值”，初始化为 0 是在给自己留余地。
  • 如果求的是 “精准装满”，除了 dp[0]，其他必须初始化为 负无穷。这是为了给系统立一个规矩：不合法的路径，我一分钱也不给你。
