二叉树陷阱：为什么‘局部合法’不等于‘全局合法’？

2026-03-28 21:30
阅读时长: 2 分钟

LeetCode 98. 验证二叉搜索树 是很多同学面试时的滑铁卢。看似简单的定义，实则隐藏着一个关于“全局约束”的考点。

1. 错误的直觉：只看父子

很多初学者写出的代码是这样的： if root.val > root.left.val and root.val < root.right.val: ...

阿彪警示：这只能保证局部合法。在 BST 中，根节点对左子树的所有节点都有上限约束，对右子树的所有节点都有下限约束。

2. 解法一：范围限定法（Top-down）

这种思路是给每一个节点设置一个“天花板”和“地板”。

  • 往左走，更新“天花板”。
  • 往右走，更新“地板”。

“每一个节点不仅要听爸爸的话，还要听爷爷甚至祖先的话。”

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def check(node, low, high):
            if not node:
                return True
            
            # 1. 检查当前节点是否在全局范围内
            if not (low < node.val < high):
                return False
            
            # 2. 递归检查左子树（上限变为当前值）
            # 3. 递归检查右子树（下限变为当前值）
            # 必须左右同时为 True 才算 True
            return check(node.left, low, node.val) and check(node.right, node.val, high)

        return check(root, float('-inf'), float('inf'))

3. 解法二：中序遍历法（阿彪推荐 🌟）

这是利用了 BST 最核心的数学特性：中序遍历（左-根-右）结果是一个严格递增序列。

逻辑拆解：

  1. 像爬楼梯一样进行中序遍历。
  2. 维护一个 pre 变量，记录刚刚走过的节点值。
  3. 只要发现当前的数字没比 pre 大，直接判死刑。

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        self.pre = float('-inf')
        def check(node):
            if not node:return True
            left = check(node.left)
            if not left:
                return False
            if node.val<=self.pre:
                return False
            self.pre = node.val # 更新前一个值为当前值
            right = check(node.right)
            return right
        return check(root)

4. 复杂度分析

  • 时间复杂度：$O(N)$。每个节点访问一次。
  • 空间复杂度：$O(H)$。取决于递归栈深度，最坏 $O(N)$，平衡时 $O(\log N)$。
